Regression and Classification using Champak Roy Books

In this lesson, we learn six important machine learning situations: linear regression with one input, linear regression with many inputs, binary classification with one input, binary classification with many inputs, multiclass classification with one input, and multiclass classification with many inputs.

Regression Predicts a number, such as book price.
Binary Classification Predicts yes or no, such as beginner friendly or not.
Multiclass Classification Predicts one class from many book categories.

We shall use three example books by Champak Roy. The data is small and imaginary, but it is perfect for understanding the concepts.

1. Linear Regression with 1 Input

Input: Pages | Output: Price

In this case, we predict the price of a book using only one input: number of pages.

Price = m × Pages + b
import numpy as np
from sklearn.linear_model import LinearRegression

# Dataset: Champak Roy books
books = [
    "Recursion Sutras",
    "Object Oriented Programming",
    "Big Book of Java Programs"
]

# One input: pages
X = np.array([
    [120],
    [220],
    [420]
])

# Output: price
y = np.array([199, 349, 599])

model = LinearRegression()
model.fit(X, y)

new_pages = 300
predicted_price = model.predict([[new_pages]])

print("Linear Regression with 1 Input")
print("Book pages:", new_pages)
print("Predicted price:", round(predicted_price[0], 2))

2. Linear Regression with Many Inputs

Inputs: Pages, Difficulty, Programs | Output: Price

Now we predict the price using more than one input. This is closer to real-world machine learning.

Price = w1 × Pages + w2 × Difficulty + w3 × Programs + b
import numpy as np
from sklearn.linear_model import LinearRegression

books = [
    "Recursion Sutras",
    "Object Oriented Programming",
    "Big Book of Java Programs"
]

# Many inputs: pages, difficulty, number of programs
X = np.array([
    [120, 2, 45],
    [220, 3, 80],
    [420, 4, 250]
])

# Output: price
y = np.array([199, 349, 599])

model = LinearRegression()
model.fit(X, y)

new_book = [[300, 3, 120]]
predicted_price = model.predict(new_book)

print("Linear Regression with Many Inputs")
print("Input: Pages=300, Difficulty=3, Programs=120")
print("Predicted price:", round(predicted_price[0], 2))

3. Binary Classification with 1 Input

Input: Pages | Output: Beginner Friendly?

Binary classification predicts one of two possible answers. Here the answer is yes or no.

Beginner Friendly = 1, Not Beginner Friendly = 0
import numpy as np
from sklearn.linear_model import LogisticRegression

# One input: pages
X = np.array([
    [120],
    [220],
    [420]
])

# Output:
# 1 = beginner friendly
# 0 = not beginner friendly
y = np.array([1, 1, 0])

model = LogisticRegression()
model.fit(X, y)

new_pages = 300
prediction = model.predict([[new_pages]])
probability = model.predict_proba([[new_pages]])

print("Binary Classification with 1 Input")
print("Book pages:", new_pages)

if prediction[0] == 1:
    print("Prediction: Beginner Friendly")
else:
    print("Prediction: Not Beginner Friendly")

print("Probability:", probability)

5. Multiclass Classification with 1 Input

Input: Pages | Output: Book Category

Multiclass classification predicts one class from more than two classes. Here we classify a book as Short Guide, Standard Textbook, or Large Reference Book.

Class Number Category
0Short Guide
1Standard Textbook
2Large Reference Book
 
import numpy as np
from sklearn.linear_model import LogisticRegression

# One input: pages
X = np.array([
    [120],
    [220],
    [420]
])

# Categories:
# 0 = Short Guide
# 1 = Standard Textbook
# 2 = Large Reference Book
y = np.array([0, 1, 2])

model = LogisticRegression()
model.fit(X, y)

new_pages = 300
prediction = model.predict([[new_pages]])

categories = {
    0: "Short Guide",
    1: "Standard Textbook",
    2: "Large Reference Book"
}

print("Multiclass Classification with 1 Input")
print("Book pages:", new_pages)
print("Predicted category:", categories[prediction[0]])
