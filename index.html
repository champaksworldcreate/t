What is Google Search Console?

Google Search Console is a free Google tool that helps you monitor how your website appears in search results. It allows you to verify ownership, submit a sitemap, inspect URLs, and review indexing issues.

In simple words: it is the control room for your website’s presence on Google Search.

Before you begin

Keep these things ready before starting:

Required

  • Your website URL
  • A Google account
  • Access to your site files, DNS, or page head section

Recommended

  • A sitemap.xml file
  • A robots.txt file
  • Important pages ready for indexing
Tip: Finalize your main site version first. For example, use either https://www.example.com or https://example.com as your main version.

Step-by-step: submit your website

Open Google Search Console.
Sign in with your Google account.
Add your property.
Choose Domain property for full coverage or URL prefix for one exact site version.
Verify ownership.
Prove that you control the website using DNS, HTML file upload, meta tag, Analytics, or Tag Manager.
Open the verified property.
Once verification succeeds, the property dashboard becomes active.
Submit your sitemap.
Go to the Sitemaps section and submit your sitemap.xml.
Inspect key pages.
Use URL Inspection to test your homepage and important landing pages.
Request indexing.
Ask Google to crawl important live pages.
Monitor results.
Review indexing, coverage, performance, and errors over time.

Verification methods

These are the most common methods used to verify ownership inside Search Console.

Method Best for How it works
DNS record Full domain verification Add a TXT record in your domain DNS settings.
HTML file upload Sites where you can upload files Download the file from Google and place it in your site root.
HTML meta tag Sites where you can edit the head section Add a verification meta tag inside the page head.
Google Analytics Sites already using Analytics Google checks your existing Analytics setup.
Google Tag Manager Sites already using GTM Google checks your existing GTM container.

Example: HTML meta tag verification

<meta name="google-site-verification" content="YOUR_VERIFICATION_CODE" />
Good practice: keep the verification method in place after success.

Submitting a sitemap

A sitemap helps Google discover important URLs on your website. It does not force indexing, but it improves discovery and structure.

Typical sitemap URL

https://yourdomain.com/sitemap.xml

How to submit it

  1. Open your verified property in Search Console.
  2. Go to Sitemaps.
  3. Enter the sitemap path or full URL.
  4. Click Submit.

Basic robots.txt example

User-agent: * Allow: / Sitemap: https://yourdomain.com/sitemap.xml
Tip: If you use multiple hosts like www and a subdomain, keep separate sitemap files when needed.

Frequently asked questions


        
Does submitting a site guarantee ranking?

        
No. It helps Google discover and understand your pages, but ranking depends on many other factors.


        
How long does indexing take?

        
It can be quick for some pages and slower for others. Requesting indexing helps, but Google still decides.


        
Should I verify subdomains separately?

        
If you use URL prefix properties, often yes. If you use domain verification, the entire domain is usually covered.


        
Can I use this for Blogger or GitHub Pages?

        
Yes. The process works for Blogger, GitHub Pages, custom domains, and subdomains.
