🧠 How MongoDB Querying Works (Beginner Explanation)

1️⃣ What is a Collection?

A collection is like a table in SQL. Example: books, users, employees.

2️⃣ What is a Document?

A document is one record (a JSON object).

{
  "BookId": 1,
  "BookName": "The Recursion Sutras",
  "Author": "Champak Roy",
  "Subject": "Recursion"
}

3️⃣ What is a Query?

A query tells MongoDB what to find.

Example: 
{ "Author": "Champak Roy" }
This means: 👉 "Find all documents where Author equals Champak Roy"

4️⃣ What is Projection?

Projection decides which fields to show.

{ "BookName": 1, "Subject": 1 }
This means: 👉 "Only show BookName and Subject fields"

5️⃣ What is Update?

Updates modify documents using operators like $set.

{ "$set": { "Subject": "OOP Programming" } }
This means: 👉 Change Subject field.
