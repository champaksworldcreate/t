Mouse Drag Thread Drawing

Drag your mouse or finger on the canvas. Every drag movement starts a small animated drawing thread.

Drag on the canvas to start threads

How this works

In Java, we may use real threads. In the browser, JavaScript usually runs on one main thread. Here, each animated brush behaves like a separate drawing thread.

The page uses requestAnimationFrame() for smooth animation. When you drag on the canvas, JavaScript creates new drawing agents. Each agent has its own position, speed, direction, color, size, and life.
