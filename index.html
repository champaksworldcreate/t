Test Rules

  1. Write clean SQL. Formatting matters.
  2. Use meaningful aliases where needed.
  3. Do not only memorize syntax. Understand the output.
  4. For every query, ask yourself: What table is needed? What rows are needed? What columns are needed? Is grouping required?
  5. For hiring practice, explain your query in one or two lines after writing it.

Database Setup

Create these tables before starting the test.

CREATE TABLE departments (
  department_id INTEGER PRIMARY KEY,
  department_name TEXT NOT NULL
);

CREATE TABLE employees (
  employee_id INTEGER PRIMARY KEY,
  employee_name TEXT NOT NULL,
  department_id INTEGER,
  salary INTEGER,
  joining_date TEXT,
  city TEXT,
  manager_id INTEGER,
  FOREIGN KEY (department_id) REFERENCES departments(department_id)
);

CREATE TABLE projects (
  project_id INTEGER PRIMARY KEY,
  project_name TEXT NOT NULL,
  department_id INTEGER,
  budget INTEGER,
  start_date TEXT,
  status TEXT,
  FOREIGN KEY (department_id) REFERENCES departments(department_id)
);

CREATE TABLE attendance (
  attendance_id INTEGER PRIMARY KEY,
  employee_id INTEGER,
  attendance_date TEXT,
  status TEXT,
  FOREIGN KEY (employee_id) REFERENCES employees(employee_id)
);

CREATE TABLE sales (
  sale_id INTEGER PRIMARY KEY,
  employee_id INTEGER,
  sale_date TEXT,
  amount INTEGER,
  product TEXT,
  FOREIGN KEY (employee_id) REFERENCES employees(employee_id)
);

Scoring Pattern

Part A SQL basics and concepts: 15 marks
Part B Simple SELECT queries: 20 marks
Part C Filtering, sorting, and conditions: 15 marks

Part A: SQL Basics and Concepts

Total: 15 marks

0 Level
1. What is SQL?

Explain SQL in simple language. Also write the full form of SQL.

Expected Answer

SQL stands for Structured Query Language. It is used to create, read, update, and delete data from relational databases.

0 Level
2. What is a table?

Explain table, row, and column using a student register example.

Expected Answer

A table stores related data. A row is one record. A column is one property. In a student table, one row may represent one student, and columns may be name, roll number, class, and marks.

Basic
3. What is a primary key?

Explain why employee_id is a good primary key in the employees table.

Expected Answer

A primary key uniquely identifies each row in a table. employee_id is a good primary key because each employee should have a unique ID.

Basic
4. What is a foreign key?

Explain the relationship between employees.department_id and departments.department_id.

Expected Answer

A foreign key connects one table to another. Here, employees.department_id refers to departments.department_id, so each employee can be connected to a department.

Basic
5. Difference between WHERE and HAVING

Explain the difference in simple words.

Expected Answer

WHERE filters rows before grouping. HAVING filters grouped results after GROUP BY.

Part B: Simple SELECT Queries

Total: 20 marks

Beginner
6. Show all departments.

Write a query to display all rows from the departments table.

Answer 
SELECT * FROM departments;
Beginner
7. Show employee names and salaries.

Display only employee_name and salary from the employees table.

Answer 
SELECT employee_name, salary
FROM employees;
Beginner
8. Rename output columns.

Display employee name as Name and salary as Monthly Salary.

Answer 
SELECT employee_name AS Name,
       salary AS "Monthly Salary"
FROM employees;
Beginner
9. Show unique cities.

Display each city only once from the employees table.

Answer 
SELECT DISTINCT city
FROM employees;
Beginner
10. Calculate annual salary.

Show employee name, monthly salary, and annual salary.

Answer 
SELECT employee_name,
       salary AS monthly_salary,
       salary * 12 AS annual_salary
FROM employees;

Intermediate
16. Count employees

17. Average salary

Find the average salary of all employees.

Answer

18. Highest and lowest salary

Find the highest salary and lowest salary.

Answer 
SELECT MAX(salary) AS highest_salary,
       MIN(salary) AS lowest_salary
FROM employees;

Find how many employees are from each city.

Answer 
SELECT city,
       COUNT(*) AS total_employees

Hiring Level
20. Cities with more than 2 employees

Find cities where more than 2 employees are working.

Answer 
SELECT city,
       COUNT(*) AS total_employees
FROM employees
GROUP BY city
HAVING COUNT(*) > 2;

Part E: Joins and Relationships

Total: 20 marks

Intermediate
21. Employee with department name

Display employee name and department name.

Answer 
SELECT e.employee_name,
       d.department_name
FROM employees e
JOIN departments d
ON e.department_id = d.department_id;
Intermediate
22. Include employees without department

Display all employees and their department names. Employees without department should also appear.

Answer 
SELECT e.employee_name,
       d.department_name
FROM employees e
LEFT JOIN departments d
ON e.department_id = d.department_id;
Hiring Level
23. Department-wise average salary

Display each department name and average salary.

Answer 
SELECT d.department_name,
       AVG(e.salary) AS average_salary
FROM departments d
JOIN employees e
ON d.department_id = e.department_id
GROUP BY d.department_name;
Hiring Level
24. Projects with department names

Display project name, budget, status, and department name.

Answer 
SELECT p.project_name,
       p.budget,
       p.status,
       d.department_name
FROM projects p
JOIN departments d
ON p.department_id = d.department_id;
Hiring Level
25. Employee and manager name

Display employee name and manager name using a self join.

Answer 
SELECT e.employee_name AS employee,
       m.employee_name AS manager
FROM employees e
LEFT JOIN employees m
ON e.manager_id = m.employee_id;

Part F: Hiring-Style Practical Tasks

Total: 15 marks

Hiring Level
26. Top 3 highest-paid employees

Find the top 3 employees by salary.

Answer 
SELECT employee_name, salary
FROM employees
ORDER BY salary DESC
LIMIT 3;
Hiring Level
27. Sales total by employee

Find total sales amount generated by each sales employee.

Answer 
SELECT e.employee_name,
       SUM(s.amount) AS total_sales
FROM employees e
JOIN sales s
ON e.employee_id = s.employee_id
GROUP BY e.employee_name
ORDER BY total_sales DESC;
Hiring Level
28. Employees who were absent at least once

Find employees who have at least one absent record.

Answer 
SELECT DISTINCT e.employee_name
FROM employees e
JOIN attendance a
ON e.employee_id = a.employee_id
WHERE a.status = 'Absent';
Hiring Level
29. Salary category

Display employee name, salary, and salary category. Use these rules:

  • Salary 60000 or above: High
  • Salary 40000 to 59999: Medium
  • Below 40000: Low
Answer 
SELECT employee_name,
       salary,
       CASE
         WHEN salary >= 60000 THEN 'High'
         WHEN salary >= 40000 THEN 'Medium'
         ELSE 'Low'
       END AS salary_category
FROM employees;
Hiring Level
30. Department performance report

Create a report showing department name, number of employees, average salary, and total project budget.

Answer 
SELECT d.department_name,
       COUNT(DISTINCT e.employee_id) AS total_employees,
       AVG(e.salary) AS average_salary,
       SUM(DISTINCT p.budget) AS total_project_budget
FROM departments d
LEFT JOIN employees e
ON d.department_id = e.department_id
LEFT JOIN projects p
ON d.department_id = p.department_id
GROUP BY d.department_name;

Final Practical Challenge

This is the final hiring-style assignment. It tests whether the student can read a business problem and convert it into SQL.

Final Challenge
Build an Employee Dashboard Query

Write one or more SQL queries to generate the following dashboard:

  1. Total number of employees
  2. Average salary
  3. Highest-paid employee
  4. Department-wise employee count
  5. Department-wise average salary
  6. Total sales by each sales employee
  7. Employees who have no department assigned
  8. Employees who were absent at least once
Sample Solution 
-- 1. Total number of employees
SELECT COUNT(*) AS total_employees
FROM employees;

-- 2. Average salary
SELECT AVG(salary) AS average_salary
FROM employees;

-- 3. Highest-paid employee
SELECT employee_name, salary
FROM employees
ORDER BY salary DESC
LIMIT 1;

-- 4. Department-wise employee count
SELECT d.department_name,
       COUNT(e.employee_id) AS total_employees
FROM departments d
LEFT JOIN employees e
ON d.department_id = e.department_id
GROUP BY d.department_name;

-- 5. Department-wise average salary
SELECT d.department_name,
       AVG(e.salary) AS average_salary
FROM departments d
LEFT JOIN employees e
ON d.department_id = e.department_id
GROUP BY d.department_name;

-- 6. Total sales by each sales employee
SELECT e.employee_name,
       SUM(s.amount) AS total_sales
FROM employees e
JOIN sales s
ON e.employee_id = s.employee_id
GROUP BY e.employee_name
ORDER BY total_sales DESC;

-- 7. Employees who have no department assigned
SELECT employee_name
FROM employees
WHERE department_id IS NULL;

-- 8. Employees who were absent at least once
SELECT DISTINCT e.employee_name
FROM employees e
JOIN attendance a
ON e.employee_id = a.employee_id
WHERE a.status = 'Absent';

  4. Final 30 minutes: solve the dashboard challenge.
