0. Big Idea

In normal Matplotlib, we usually draw using two coordinates: 

x, y

In 3D Matplotlib, every point has three coordinates: 

x, y, z
Think of 3D plotting as normal Matplotlib plus one extra axis and a movable camera.
X axis Left and right direction.
Y axis Forward and backward direction.
Z axis Up and down direction.

1. Setup

First 3D plot

import matplotlib.pyplot as plt

fig = plt.figure()
ax = fig.add_subplot(projection="3d")

ax.scatter(1, 2, 3)

ax.set_title("My First 3D Point")
ax.set_xlabel("X")
ax.set_ylabel("Y")
ax.set_zlabel("Z")

plt.show()

2. Main 3D Plot Types

Plot Function Use Case
3D Scatter ax.scatter(x, y, z) Raw data points, customer data, marks, features
3D Line ax.plot(x, y, z) Paths, spirals, trajectories
Surface ax.plot_surface(X, Y, Z) Mathematical functions, landscapes, ML loss
Wireframe ax.plot_wireframe(X, Y, Z) Grid structure of a surface
Contour ax.contour3D(X, Y, Z) Height lines, maps, loss levels
Vector ax.quiver(x, y, z, u, v, w) Direction, force, motion, linear algebra

3. Meshgrid

Surface plots need a grid. That is why we use: 

X, Y = np.meshgrid(x, y)

Then we calculate: 

Z = f(X, Y)

Example: 

x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)

X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

4. Camera Angle

A 3D plot is like an object inside a box. You can rotate the camera. 

ax.view_init(elev=30, azim=45)
elev Vertical viewing angle.
azim Horizontal rotation angle.
box aspect Controls the shape of the 3D box.

5. 3D for Machine Learning

3D plots are very useful for explaining machine learning loss. For example, loss can depend on weight and bias. 

Loss = (Weight - 2)**2 + (Bias - 1)**2

The lowest point of the surface is the best model parameter area.
