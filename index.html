How to use:
1. Click on the map to add cities.
2. Drag any city marker to reposition it.
3. Press Solve to build a loop.
4. Use Animate to watch the tour being drawn.
5. Try Nearest + 2-opt to improve the path.

Distances here are straight-line geographic estimates using the Haversine formula, so this visualizer is great for learning and experimentation.

Interactive TSP Lab Add, drag, solve, animate, compare. Tip: random points are created inside the current map view.
