1) What is querySelector()?

document.querySelector(selector) finds the first element that matches a CSS selector. If nothing matches, it returns null.

Example
// First element with id="title"
const title = document.querySelector("#title");

// First element with class="card"
const card = document.querySelector(".card");

// First <p> tag
const p = document.querySelector("p");

console.log(title, card, p);
Remember
Returns only one element.
If you want all matching elements, use querySelectorAll().
Null-safe: Always check before using properties. 
const el = document.querySelector(".missing");
if (el) el.classList.add("ok");

2) querySelectorAll() & NodeList

document.querySelectorAll(selector) returns all matches as a NodeList. NodeList supports forEach, but it’s not a full Array. 

const buttons = document.querySelectorAll(".btn");

// NodeList supports forEach:
buttons.forEach(btn => btn.classList.add("ready"));

// If you want Array methods like map/filter:
const arr = Array.from(buttons);

3) Selectors you must know

// ID
document.querySelector("#nav");

// Class
document.querySelector(".card");

// Tag
document.querySelectorAll("li");

// Descendant (space)
document.querySelector(".card h2");

// Direct child (>)
document.querySelector("ul > li");

// Multiple selectors (,)
document.querySelector("h1, h2, h3");

// Attribute
document.querySelector("input[type='password']");

// Attribute starts-with / ends-with / contains
document.querySelector("a[href^='https']");
document.querySelector("img[src$='.png']");
document.querySelector("div[class*='active']");
Pro tip: If you can style it in CSS, you can select it in JS.

4) Scoping: search inside an element

Instead of searching the whole document, first pick a container and then query inside it. This keeps code clean and avoids accidental matches. 

const card = document.querySelector(".card");

// Only searches inside .card
const btn = card.querySelector("button");

5) Real-world patterns

Pattern A: Toggle menu

const menuBtn = document.querySelector("#menuBtn");
const menu = document.querySelector("#menu");

menuBtn.addEventListener("click", () => {
  menu.classList.toggle("open");
});

Pattern B: Read form values

const email = document.querySelector("input[name='email']").value;
const pass  = document.querySelector("input[name='password']").value;

console.log({ email, pass });

Pattern C: Highlight current nav link

document.querySelectorAll("nav a").forEach(a => {
  if (a.href === location.href) a.classList.add("active");
});

6) Common mistakes

  1. Forgetting # for id and . for class: 
    querySelector("title")   // selects <title> tag (not #title)
querySelector("#title")  // correct for id
  2. Expecting multiple elements from querySelector: 
    document.querySelector(".item") // only the first one
  3. Crashing on null: 
    document.querySelector(".missing").textContent = "Hi"; // crash
  4. NodeList isn’t Array: 
    document.querySelectorAll("li").map(...) // ❌ no map
Array.from(document.querySelectorAll("li")).map(...) // ✅

Cheat sheet (copy)
// querySelector (first match)
document.querySelector("#id");
document.querySelector(".class");
document.querySelector("tag");

// querySelectorAll (all matches)
document.querySelectorAll("li");

// Descendant / child
document.querySelector(".card h2");
document.querySelector("#list > li");

// Multiple selectors
document.querySelector("h1, h2");

// Attributes
document.querySelector("input[type='password']");
document.querySelector("a[href^='https']");
document.querySelector("img[src$='.png']");
document.querySelector("div[class*='active']");

// Scoped query (cleaner)
const box = document.querySelector(".box");
box.querySelector("button");
Micro rule: When your selection is wrong, print it. 
const x = document.querySelector(".something");
console.log("selected:", x);
