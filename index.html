1. What you will build

You will build a Student CRUD app with these features:

  • Create a new student
  • Read the list of students
  • Update a student
  • Delete a student

2. Install MySQL

Download MySQL Installer from the official website:

👉 Download MySQL Installer

Steps:

  1. Run installer
  2. Select Developer Default
  3. Keep port as 3306
  4. Set root password (example: root123)
  5. Finish installation
After installation, open MySQL Workbench to manage database visually.

3. Running SQL (VERY IMPORTANT)

Option 1: MySQL Workbench

  1. Open MySQL Workbench
  2. Click your connection
  3. Open SQL editor
  4. Type SQL query
  5. Click ⚡ Execute button

Option 2: Command Line

mysql -u root -p

Then enter password and run SQL:

SHOW DATABASES;
CREATE DATABASE springdemo;
USE springdemo;
Every SQL statement ends with ;

4. Create the MySQL database

CREATE DATABASE springdemo;
USE springdemo;

Run the project

.\gradlew.bat bootRun

Open:

http://localhost:8080/students
