Level 0

What is DNS?

DNS means Domain Name System. It is like the phonebook or address book of the internet. 

You remember: curesiahealth.com
Computer needs: 185.199.108.153
Simple idea: DNS converts human-friendly domain names into machine-friendly server addresses.

Main DNS Record Types

Record Meaning Example Used for
A Domain to IPv4 address @ → 185.199.108.153 Website hosting
AAAA Domain to IPv6 address @ → 2606:50c0:8000::153 IPv6 hosting
CNAME Name to another domain www → champak-s-world.github.io Subdomains
MX Email routing @ → mail provider Business email
TXT Text verification/security google-site-verification=... Google, SPF, DKIM
NS Nameserver ns19.domaincontrol.com Who controls DNS
SOA Zone authority info Primary nameserver info DNS administration

A Record

Use A record when you want a domain to point directly to an IPv4 server address.

Type: A
Host: @
Value: 185.199.108.153

CNAME Record

Use CNAME when one name should point to another domain name.

Type: CNAME
Host: www
Value: champak-s-world.github.io

NS Record

NS decides where DNS is controlled.

Level 4

GitHub Pages DNS Setup

For GitHub Pages root domain like:

curesiahealth.com

Add these A records:

Type: A
Host: @
Value: 185.199.108.153

Type: A
Host: @
Value: 185.199.109.153

Type: A
Host: @
Value: 185.199.110.153

Type: A
Host: @
Value: 185.199.111.153

Add this CNAME for www:

Type: CNAME
Host: www
Value: champak-s-world.github.io
Do not use CNAME for the root domain @ when setting up GitHub Pages apex domain. Use the four A records for @.

Level 5

DNS and HTTPS

HTTPS does not work immediately after DNS setup. The usual order is:

1. DNS records added
2. DNS propagation
3. GitHub verifies domain
4. GitHub issues SSL certificate
5. Enforce HTTPS becomes available
6. Website opens securely
If HTTP works but HTTPS does not, your DNS may be almost correct. GitHub may still be checking or issuing the certificate.

TTL

TTL means Time To Live. It controls how long DNS results are cached.

TTL: 1 Hour

This means updates may take time to appear everywhere.

Propagation

Propagation means DNS changes spreading across internet resolvers.

Fast: 5 minutes
Common: 30 minutes to 6 hours
Maximum: 24 to 48 hours

Level 7

Expert Concepts

Authoritative DNS

The authoritative DNS server is the final source of truth for your domain’s records. If your nameserver is domaincontrol.com, then that DNS provider controls your DNS entries.

Recursive resolver

A recursive resolver is usually provided by ISP, Google DNS, Cloudflare DNS, or your operating system. It asks other DNS servers and returns the answer to your browser.

Wildcard DNS 
*.example.com → one server

This sends all subdomains to one target.

CDN DNS

A CDN like Cloudflare can sit between your visitors and your website to improve speed and security.

Email security DNS

SPF, DKIM, and DMARC are TXT-based DNS records used to protect email identity.
