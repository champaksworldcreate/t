1. Overview

Data cleaning is the process of converting messy, incomplete, inconsistent, duplicated, and wrongly typed data into a form that is ready for analysis.

Missing values

Empty cells, unknown values, blanks, None, NaN, or values like "N/A".

Duplicates

Repeated rows or repeated records that can distort counting, averages, and reports.

Wrong datatypes

Numbers stored as text, dates stored as text, and categories with inconsistent spelling.

2. Why data cleaning matters

Data analysis is only as good as the data. If the data is dirty, every result after that becomes doubtful.

Problem Example Damage
Missing values Age is empty for many students Mean age becomes incorrect or impossible
Duplicates Same student appears twice Counts and averages become biased
Wrong datatype "85" stored as text instead of number Mathematical operations fail
Messy strings " male ", "MALE", "Male" One category becomes many fake categories
Impossible values Marks are 150 out of 100 Reports become misleading

4. Step one: inspect the data

Before cleaning, never start blindly. First inspect the dataset. 

print(df.head())
print(df.tail())
print(df.info())
print(df.describe(include="all"))
print(df.isnull().sum())
Command Meaning
df.head() Shows the first 5 rows
df.tail() Shows the last 5 rows
df.info() Shows column names, non-null counts, and datatypes
df.describe(include="all") Shows summary for numeric and non-numeric columns
df.isnull().sum() Counts missing values in each column
Inspection is like a doctor checking the patient before giving medicine.

5. Missing values and null handling

In Pandas, missing values are usually represented as NaN. But real messy datasets may also contain empty strings, spaces, "N/A", "missing", or "absent".

Detect normal missing values

print(df.isnull())
print(df.isnull().sum())

Convert fake missing values into real missing values

df = df.replace(["", " ", "N/A", "NA", "missing", "absent"], np.nan)

print(df.isnull().sum())
First convert fake missing values to np.nan. Then Pandas can handle them properly.

6. fillna: filling missing values

fillna() is used when we want to replace missing values with some suitable value.

Fill with fixed value

df["Name"] = df["Name"].fillna("Unknown")
df["Gender"] = df["Gender"].fillna("Unknown")
df["City"] = df["City"].fillna("Unknown")

Fill numeric column with mean or median

For numeric columns, median is often safer than mean because one very high or very low value can distort the mean. 

df["Age"] = df["Age"].fillna(df["Age"].median())
df["Math"] = df["Math"].fillna(df["Math"].median())
df["Science"] = df["Science"].fillna(df["Science"].median())

Common fillna options

Method Example Use case
Fixed value fillna("Unknown") Names, city, category columns
Mean fillna(df["Age"].mean()) Numeric column without extreme values
Median fillna(df["Marks"].median()) Numeric column with possible extreme values
Mode fillna(df["City"].mode()[0]) Most common category

7. dropna: removing missing values

dropna() removes rows or columns containing missing values. Use it carefully because you may lose useful data.

Drop rows with any missing value

df_without_missing = df.dropna()

Drop rows only if important columns are missing

df = df.dropna(subset=["Student_ID", "Name"])

Drop columns with too many missing values

# Example:
# df = df.drop(columns=["Very_Bad_Column"])
Rule: Do not use dropna() blindly. First ask: is this row useless, or can it be repaired?

8. Duplicate control

Duplicate rows can silently damage analysis.

Check duplicates

print(df.duplicated())
print("Duplicate rows:", df.duplicated().sum())

Remove exact duplicate rows

df = df.drop_duplicates()

Remove duplicates using a specific column

In student data, Student_ID should usually be unique. 

df = df.drop_duplicates(subset=["Student_ID"], keep="first")
Code Meaning
df.duplicated() Returns True for duplicate rows
df.duplicated().sum() Counts duplicate rows
df.drop_duplicates() Removes duplicate rows
subset=["Student_ID"] Checks duplicates based on Student_ID only

9. Datatype fixes and type conversion

Sometimes numbers are stored as strings. Pandas cannot correctly calculate until we convert them.

Check datatypes

print(df.dtypes)

Convert to numeric

df["Age"] = pd.to_numeric(df["Age"], errors="coerce")
df["Math"] = pd.to_numeric(df["Math"], errors="coerce")
df["Science"] = pd.to_numeric(df["Science"], errors="coerce")

errors="coerce" means: if a value cannot be converted, convert it to NaN.

Fix impossible values

In our dataset, Math marks contain 150. If marks are out of 100, this is invalid. 

df.loc[df["Math"] > 100, "Math"] = np.nan
df.loc[df["Science"] > 100, "Science"] = np.nan

Fill after conversion

df["Age"] = df["Age"].fillna(df["Age"].median())
df["Math"] = df["Math"].fillna(df["Math"].median())
df["Science"] = df["Science"].fillna(df["Science"].median())
Convert first, then fill. If you fill before conversion, bad text values may remain hidden.

10. String cleanup

Text columns often contain extra spaces and inconsistent case.

Remove spaces

df["Name"] = df["Name"].str.strip()
df["Gender"] = df["Gender"].str.strip()
df["City"] = df["City"].str.strip()

Fix case

df["Name"] = df["Name"].str.title()
df["Gender"] = df["Gender"].str.title()
df["City"] = df["City"].str.title()

Replace inconsistent categories

df["Gender"] = df["Gender"].replace({
    "Male": "Male",
    "Female": "Female",
    "Unknown": "Unknown"
})
Function Meaning
.str.strip() Removes spaces from beginning and end
.str.lower() Converts text to lowercase
.str.upper() Converts text to uppercase
.str.title() Converts text to title case
.replace() Replaces one value with another

"""

import pandas as pd
import numpy as np

print("=" * 70)
print("CLEANED DATASET NOTEBOOK")
print("=" * 70)

# ------------------------------------------------------------
# 1. Create messy dataset
# ------------------------------------------------------------

data = {
    "Student_ID": [1, 2, 3, 4, 5, 5, 6, 7, 8, 9],
    "Name": [" Aarav ", "siya", "MOHAN", "Riya", "Kabir", "Kabir", " Anaya", None, "Dev", "Meera "],
    "Gender": [" Male", "female ", "MALE", "Female", "male", "male", "FEMALE", "Female", None, " female"],
    "Age": ["15", "16", None, "15", "17", "17", "sixteen", "16", "15", ""],
    "Math": ["85", "90", "78", None, "88", "88", "92", "absent", "150", "81"],
    "Science": [80, 95, None, 72, 88, 88, 91, 84, 77, ""],
    "City": [" Varanasi", "varanasi ", "Lucknow", "LUCKNOW", "Patna", "Patna", None, "Delhi ", "delhi", "Kanpur"]
}

df = pd.DataFrame(data)

print("\n1. RAW DATASET")
print(df)

# Save before copy
before = df.copy()

# ------------------------------------------------------------
# 2. Inspect raw data
# ------------------------------------------------------------

print("\n2. BASIC INSPECTION")
print("\nFirst rows:")
print(df.head())

print("\nInformation:")
print(df.info())

print("\nMissing values before cleaning:")
print(df.isnull().sum())

print("\nDuplicate rows before cleaning:", df.duplicated().sum())

print("\nDatatypes before cleaning:")
print(df.dtypes)

# ------------------------------------------------------------
# 3. Convert fake missing values to np.nan
# ------------------------------------------------------------

print("\n3. CONVERT FAKE MISSING VALUES TO REAL NaN")

df = df.replace(["", " ", "N/A", "NA", "missing", "absent"], np.nan)

print(df.isnull().sum())

# ------------------------------------------------------------
# 4. Remove duplicates
# ------------------------------------------------------------

print("\n4. REMOVE DUPLICATES")

df = df.drop_duplicates()
df = df.drop_duplicates(subset=["Student_ID"], keep="first")

print("Duplicate rows after cleaning:", df.duplicated().sum())

# ------------------------------------------------------------
# 5. String cleanup
# ------------------------------------------------------------

print("\n5. STRING CLEANUP")

text_columns = ["Name", "Gender", "City"]

for col in text_columns:
    df[col] = df[col].astype("string")
    df[col] = df[col].str.strip()
    df[col] = df[col].str.title()

print(df[text_columns])

# ------------------------------------------------------------
# 6. Fill missing text values
# ------------------------------------------------------------

print("\n6. FILL MISSING TEXT VALUES")

df["Name"] = df["Name"].fillna("Unknown")
df["Gender"] = df["Gender"].fillna("Unknown")
df["City"] = df["City"].fillna("Unknown")

print(df[["Name", "Gender", "City"]])

# ------------------------------------------------------------
# 7. Type conversion
# ------------------------------------------------------------

print("\n7. TYPE CONVERSION")

numeric_columns = ["Age", "Math", "Science"]

for col in numeric_columns:
    df[col] = pd.to_numeric(df[col], errors="coerce")

print(df.dtypes)

# ------------------------------------------------------------
# 8. Fix impossible values
# ------------------------------------------------------------

print("\n8. FIX IMPOSSIBLE VALUES")

df.loc[df["Math"] > 100, "Math"] = np.nan
df.loc[df["Science"] > 100, "Science"] = np.nan
df.loc[df["Age"] <= 0, "Age"] = np.nan

print(df)

# ------------------------------------------------------------
# 9. Fill missing numeric values
# ------------------------------------------------------------

print("\n9. FILL MISSING NUMERIC VALUES")

for col in numeric_columns:
    median_value = df[col].median()
    df[col] = df[col].fillna(median_value)

print(df[numeric_columns])

# ------------------------------------------------------------
# 10. Create new analysis-ready columns
# ------------------------------------------------------------

print("\n10. CREATE ANALYSIS-READY COLUMNS")

df["Total"] = df["Math"] + df["Science"]
df["Average"] = df["Total"] / 2

def result_status(avg):
    if avg >= 80:
        return "Excellent"
    elif avg >= 60:
        return "Good"
    else:
        return "Needs Practice"

df["Status"] = df["Average"].apply(result_status)

print(df)

# ------------------------------------------------------------
# 11. Before/after comparison
# ------------------------------------------------------------

print("\n11. BEFORE / AFTER COMPARISON")

print("\nBefore shape:", before.shape)
print("After shape:", df.shape)

print("\nMissing values before:")
print(before.isnull().sum())

print("\nMissing values after:")
print(df.isnull().sum())

print("\nDatatypes before:")
print(before.dtypes)

print("\nDatatypes after:")
print(df.dtypes)

print("\nBefore first rows:")
print(before.head())

print("\nAfter first rows:")
print(df.head())

# ------------------------------------------------------------
# 12. Analysis after cleaning
# ------------------------------------------------------------

print("\n12. SIMPLE ANALYSIS AFTER CLEANING")

print("\nAverage Math marks:", df["Math"].mean())
print("Average Science marks:", df["Science"].mean())
print("Highest average:", df["Average"].max())
print("Lowest average:", df["Average"].min())

print("\nCity-wise average:")
print(df.groupby("City")["Average"].mean())

print("\nStatus count:")
print(df["Status"].value_counts())

# ------------------------------------------------------------
# 13. Save cleaned dataset
# ------------------------------------------------------------

print("\n13. SAVE CLEANED DATASET")

df.to_csv("cleaned_students.csv", index=False)

print("Cleaned dataset saved as cleaned_students.csv")

print("\n" + "=" * 70)
print("NOTEBOOK COMPLETE")
print("=" * 70)

13. Cleaning pipeline explained

Step Code idea Reason
Create copy before = df.copy() Needed for before/after comparison
Replace fake missing replace([...], np.nan) Makes missing values detectable
Remove duplicates drop_duplicates() Prevents repeated records
Clean strings str.strip(), str.title() Fixes spaces and case problems
Convert datatypes pd.to_numeric() Makes calculation possible
Fix invalid values df.loc[condition, column] = np.nan Removes impossible data
Fill missing values fillna() Repairs useful rows
Save output to_csv() Creates reusable cleaned dataset
