Threaded Drawing Simulation

A Java multithreaded drawing idea recreated with HTML Canvas and JavaScript. Each moving brush behaves like an independent drawing thread.

How this works

Java uses real threads. In the browser, JavaScript usually runs on one main thread. But we can simulate threaded drawing by creating many independent drawing objects. Each object has its own position, speed, direction, color, and drawing style.

The animation loop uses requestAnimationFrame(). On every frame, each drawing agent updates itself. This creates the visual effect of multiple threads drawing at the same time.
