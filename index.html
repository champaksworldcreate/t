Spring Boot + MySQL + Thymeleaf (Full CRUD)

1. Install MySQL

Download MySQL Installer from official site:

👉 https://dev.mysql.com/downloads/installer/

Steps:
  • Download installer
  • Choose Developer Default
  • Set root password (example: root123)
  • Keep port = 3306
  • Finish installation
---

2. Install MySQL Workbench (GUI)

Download:

👉 https://dev.mysql.com/downloads/workbench/

Use Workbench to:
  • Create database
  • Run SQL
  • View tables
---

3. How to Run SQL

Option 1: Using MySQL Workbench

  • Open Workbench
  • Click your connection
  • Click "SQL +" tab
  • Write query
  • Click ⚡ Execute button
Example: 
CREATE DATABASE springdemo;

USE springdemo;

CREATE TABLE student (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(150)
);
---

Option 2: Using Command Line

Open terminal: 
mysql -u root -p
Enter password. Then run: 
CREATE DATABASE springdemo;
USE springdemo;
SHOW TABLES;
---

4. Important SQL Commands

SHOW DATABASES;

USE springdemo;

SHOW TABLES;

SELECT * FROM student;

INSERT INTO student(name, email)
VALUES ('Champak', 'champak@test.com');

DELETE FROM student WHERE id = 1;
---

5. Connect Spring Boot

spring.datasource.url=jdbc:mysql://localhost:3306/springdemo
spring.datasource.username=root
spring.datasource.password=root123

spring.jpa.hibernate.ddl-auto=update
---

6. What Happens Internally

Flow:
  • User submits form
  • Controller receives data
  • Service processes it
  • Repository saves to MySQL
  • Data stored in table
---

7. Test Your Setup

  • Run Spring Boot
  • Open: http://localhost:8080/students
  • Add student
  • Check in MySQL:
SELECT * FROM student;
---

8. Common Errors

  • Access denied → wrong password
  • Cannot connect → MySQL not running
  • Table not created → check ddl-auto=update
  • Port issue → change 3306
---
