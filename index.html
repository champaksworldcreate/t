Part A • Concepts

Clear definitions and a mental model students can repeat.

Git vs GitHub

Git local tool
Git is a version control system. It keeps a history of your project on your computer: commits, branches, and merges.
GitHub online platform
GitHub hosts Git repositories on the internet. It adds collaboration features like Pull Requests, Issues, and Reviews.
Mental model easy to remember
Commit = snapshot of your project.
Branch = alternate timeline for a feature.
Remote = online copy (GitHub).
Push = send commits to remote.
Pull = bring commits from remote.

Part B • Core Commands (Copy + Practice)

Each block has copy + “Run in terminal lab” buttons.

Check Git installation setup
git --version
Shows your installed Git version.
Set identity one time
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
Git uses this name and email for commits.
Create project folder practice
mkdir pp-git-lesson1
cd pp-git-lesson1
Creates a folder and enters it.
Initialize repo git init
git init
Starts tracking this folder with Git.
Check status daily
git status
Shows modified/untracked files and what is staged.
Stage + commit snapshot
git add .
git commit -m "Initial commit"
add chooses changes; commit saves a snapshot with a message.
View history timeline
git log --oneline
Shows a compact list of commits.
Connect to GitHub remote
git remote add origin https://github.com/YOUR_USERNAME/pp-git-lesson1.git
git remote -v
Adds a remote named origin (your GitHub repo).
Push commits publish
git push -u origin main
Sends your local commits to GitHub. -u sets tracking for next pushes.
Pull updates sync
git pull
Fetches and merges remote changes into your current branch.

Part C • Branching (Safe Feature Work)

Create a branch, commit a feature, merge into main.

Create branch feature
git checkout -b feature-about
Creates and switches to a new branch.
Commit feature work commit
git add .
git commit -m "Add about section"
In a real repo, you would edit files before this commit.
Merge into main merge
git checkout main
git merge feature-about
Brings branch changes back into main.

Part D • Homework

Simple tasks that build real Git muscle memory.

Homework 1 required
Create a repo named pp-profile with an index.html. Make three commits (small improvements each time) and push to GitHub.
Homework 2 optional
Create a branch feature-contact, add a contact section, commit, merge into main, and push.
Daily workflow habit
git status
git add .
git commit -m "Describe your change"
git push
