UI Schema (v1)

Root object: {"$schema":"pp-ui/v1","title":"...","children":[...]}

Element fields:

  • type: container | row | card | title | text | badge | divider | button | input | select | image | link
  • text: visible text
  • value: input/select default OR href/src
  • id, class: optional
  • style: CSS-in-JS object
  • attrs: safe attributes (placeholder, target, rel, alt…)
  • children: nested elements

Buttons are safe-only. Use: toast:Hello, open:https://..., copy:some text.

Help & How to use

This page edits JSON and builds UI from it. Safe rendering only (no scripts).

1) Quick start (3 steps)
  1. Click ✨ Example.
  2. Edit JSON inside JSON Editor.
  3. Click 🪄 Build UI to render it in the preview.
2) Minimal schema
{ "$schema": "pp-ui/v1", "title": "My UI", "children": [ { "type": "card", "children": [ { "type": "title", "text": "Hello" }, { "type": "text", "text": "Built from JSON." } ]} ] }
3) Safety rules
  • Only http(s) and relative URLs allowed.
  • Attributes starting with on* are blocked.
  • No JS is executed from JSON.
